# AI Companion — スマホ起動版（PWA）

このフォルダはホーム画面から起動できるPWA用の試作です。

## 重要
PWAは `file://` からはホーム画面インストールできません。
HTTPSで配信されたURLをChromeで開く必要があります。

## Android（Chrome）
1. HTTPSでこのフォルダを公開する
2. ChromeでURLを開く
3. Chromeの「︙」→「ホーム画面に追加」または「アプリをインストール」
4. ホーム画面の「AI Companion」から起動

## この版
- 3Dキャラクター
- テキスト会話
- 音声読み上げ
- 対応ブラウザで音声入力
- PWAマニフェスト
- オフライン用サービスワーカー
- ホーム画面用アイコン

※ 現在はAI APIではなくローカルの簡易応答です。
